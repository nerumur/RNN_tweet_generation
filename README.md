# RNN_tweet_generation
A deep learning project that demonstrates how to build and train a Long Short-Term Memory (LSTM) network from scratch to generate new, human-like text. The model is trained on a corpus of tweets about the coronavirus pandemic, learning to mimic the style and context of the original data.

Key Features:
- Data preprocessing and cleaning of raw tweet text.
- Custom implementation of an RNN core using Sonnet.
- Model built with Keras/TensorFlow using Embedding, LSTM, and Dense layers.
- Text generation function that takes a seed string and predicts subsequent words.
